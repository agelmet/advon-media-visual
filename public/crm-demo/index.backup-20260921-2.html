Sync setup

Cross-device sync needs one value stored on the server. This is not your passphrase and cannot be turned back into it — it is a one-way fingerprint.

Your CRM_AUTH_HASH:

—

In Netlify → your site → Site configuration → Environment variables, add:

  1. CRM_AUTH_HASH — the value above
  2. CRM_GH_REPO — the private data repo, e.g. agelmet/advon-crm-data
  3. CRM_GH_TOKEN — a GitHub token with Contents read & write on that repo

Then redeploy the site. Full instructions are in README-SYNC.md in the website repo.
